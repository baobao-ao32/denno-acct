# 会計報告書 生成器（試作）

公式テンプレに値を差し込む Layer 2 の試作。レイアウトは作り直さない。
出力は編集可能な .xlsx / .pptx のまま。人間が MS Office で確認・修正した後に PDF 化する。

## 構成
- `generate.py` — 生成器（openpyxl / python-pptx）
- `sample_data.py` — サンプル年度データ（Layer 1 の集計出力の代わり。本番では GAS の集計 JSON に差し替える）
- `templates/` — 公式テンプレのコピー（原本は `~/workspace/user/files/upload.*`、変更なし）
- `out/` — 生成物（サンプル出力）
- `.venv` — Python 仮想環境（`python generate.py` はここの python で実行）

## 使い方
```bash
cd ~/workspace/denno-acct-v2/report-generator
../.venv/bin/python generate.py
# out/2025年度_電脳サークル_収支報告書.xlsx
# out/2025年度_電脳サークル_領収証等一覧.pptx
```

## サンプルで検証済みのこと（2026-11-24、LibreOffice で描画確認）
- 収支報告書：収入合計 ¥98,400 / 支出合計 ¥90,800 / 差引 ¥7,600 /
  証明できない額 ¥2,000 / 直接経費 ¥88,800。収入の前年度増減 +10,000 / +6,000 / -。
  支出は（大分類, 科目）8グループで15行以内。署名欄あり
- 領収証等一覧：表紙（団体名・年度）+ 大分類見出し + 領収証 11枚を 3列×2行グリッドで配置。
  複数カテゴリに跨る領収証（2025-11-01）は最大割合の科目（印刷製本費・参加出展費）に配置。
  領収書なしの取引（2026-01-18）は一覧に載らず、証明できない額に計上
- テンプレの数式（合計・差引）は残し、MS Office 起動時に再計算されるよう fullCalcOnLoad を設定

## 試作のための仮決め（本番前に要確認）
- 団体名は「電脳サークル」で仮置き（正式登録名を確認すること）
- 署名は概要の例文の名前で仮置き
- 繰越金を収入に入れていない
- 領収証は合成サンプル画像（本番では Drive の実ファイルを使う。PDF 領収証は画像化する工程が要る）

## 既知の注意点
- 報告期間の終了日（P4セル）が LibreOffice の描画で途切れて見える。テンプレ側のセル幅の問題と思われる。
  MS Office で開いて確認すること。生成器はこのセルを触っていない
- 領収証画像はアスペクト比を保ってセル内に収めるため、縦長レシートは左右に余白ができる

## 本番モード（実データ）

年度フォルダを Drive から zip でダウンロード・解凍し、そのフォルダを指定する。

```
python generate.py --input <解凍した年度フォルダ>
```

- 入力: フォルダ内の「○○年度会計記録.xlsx」（zip化で自動的にxlsx化されたもの）
  と「領収書/<大分類>/」以下の領収書ファイル群
- 生成前に検査を行う。致命的な問題（領収書ファイルの欠落、金額の不一致、
  集計タブと明細の不一致、報告書の行数上限超過）があれば生成を中止する
  （終了コード2）。台帳に無いファイル等の軽微な問題は警告のみ
- PDFの領収書は pdftoppm（poppler）で画像化して配置する（複数ページは全ページ）
- 依存: python-pptx, openpyxl, Pillow + poppler-utils（pdftoppm）

## 実行環境（uv）

依存は uv で管理する（pyproject.toml / uv.lock）。初回は `uv run` が
自動で .venv を作って同期する。

```
uv run python generate.py --input <解凍した年度フォルダ>
```

pdftoppm（poppler）だけは uv で管理できないシステム依存なので、
別途インストールしておくこと。
