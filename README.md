# denno-acct（電脳サークル会計システム v2）

大学サークル「電脳サークル」の会計管理システム。v1（Googleフォーム + GAS）の破壊的再設計版。

## 技術スタック

| 層 | 採用技術 | 備考 |
|---|---|---|
| 提出フォーム | Cloudflare Pages（静的配信）+ 素のJavaScript (ES Modules) | ビルド工程なし。フレームワークを使わないのは、後任への引き継ぎ時に学習コストをゼロにするため |
| API中継 (BFF) | Cloudflare Worker | APIトークンを Secret に保持し、ブラウザに露出させない。GAS Web App の CORS / リダイレクト問題もここで吸収する |
| 台帳コア | Google Apps Script (GAS) | 年度別スプレッドシート（取引明細 + 自動集計タブ）と Drive の領収書フォルダを管理 |
| 報告書生成 | ローカル Python (openpyxl / python-pptx) | 公式テンプレへ差し込む方式。出力は編集可能な xlsx / pptx のまま（PDF化は人間が行う） |

Cloudflare側の制約: Workers無料枠は 10万リクエスト/日・CPU時間に上限があるが、本システムの規模（サークル内の提出のみ）では問題にならない。ランタイムは V8 (JavaScript) のみでネイティブバイナリは動かないため、画像変換（HEIC→JPEG）はブラウザ側、PDF→画像変換は生成器（ローカルPython）側で行う分担にしている。

## ディレクトリ

- `form/` — 提出フォーム（収入報告 / 支出報告）
  - `masters.js` — カテゴリ・科目・支払方法のマスタ定義。**保存するのはID、表示名はここから引く**
  - `app.js` — 入力検証（用途金額の合計 = 領収書全体の金額 の照合ほか）、HEIC変換、SHA-256計算、送信
- `worker/` — Cloudflare Worker。`/api/submit` の検証と GAS への転送。`GAS_ENDPOINT` 未設定時はモック応答
- `docs/` — 設計ドキュメント（v2設計、管理部分仕様、報告書データ仕様）
- `gas/` — （予定）台帳コア
- `report-generator/` — （予定）報告書生成器。試作は別途保管

## データの置き場所（Googleドライブ）

```
会計/
  テンプレート_会計記録   （年度スプシのテンプレ。これをコピーして年度分を作る）
  ○○年度/
    ○○年度会計記録       （スプレッドシート: 取引明細 / サマリ / 収入 / 支出 / 設定）
    領収書/
      運営費/  制作練習費/  参加出展費/
```

## 主な業務ルール

- 年度は4月スタート。収入の年度帰属は報告日、支出は購入日で判定する
- 前年度繰越金は収支報告書に載せない（スプレッドシート上でのみ確認可能にする）
- 複数カテゴリに跨る領収書は、金額割合が最大のカテゴリに帰属させる（保存フォルダ・領収証等一覧とも同じルール）
- 領収書は1回の提出で最大5件、用途は1領収書あたり最大10件。超える場合は提出を分け、ファイルのハッシュ照合で同一領収書への用途追記として処理する（ファイルは複製しない）
- 領収書がない支出も、証明不可フラグ + 理由必須で登録できる

## ローカルでフォームを確認する

```sh
cd form
python3 -m http.server 8000
# http://localhost:8000 を開く。APIが無い環境では送信ペイロードが画面下部に表示される
```

## デプロイ（概要）

1. `form/` を Cloudflare Pages にデプロイ
2. `worker/` をデプロイし、Pages のドメインの `/api/*` にルートを割り当てる
3. `wrangler secret put API_TOKEN` でトークンを設定し、`GAS_ENDPOINT` に GAS Web App の URL を設定する
